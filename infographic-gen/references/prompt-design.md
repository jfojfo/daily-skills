# Prompt 设计指南

## 先整理内容

先建立“事实清单”，再写视觉 prompt。将源材料压缩为：

- 1 个主标题：直接说明主题
- 1 个副标题：说明价值、范围或读图方式
- 3 个信息组：每组 3–6 条
- 1 个结论：作为底部目标条

优先保留决策相关信息、关键数字、步骤、约束和风险。删除背景套话、同义重复、实现细枝末节。不同栏目不要重复同一条事实。

默认使用“是什么 / 怎么做 / 注意什么”三栏。内容关系不适合三栏时，改用：

| 信息关系 | 推荐版式 |
|---|---|
| 先后步骤 | 横向或纵向时间轴 |
| 两组差异 | 双栏对比 |
| 四类并列 | 2×2 网格 |
| 中心概念与分支 | 中心辐射或环形 |
| 单一路径且内容较长 | 竖版流程图 |

需要特殊版式时，从 [样本库索引](sample-library.md) 找相近骨架。

## 选择视觉风格

### Business

- 使用低饱和莫兰迪色、雾白背景、充足留白、扁平线性图标。
- 适合正式汇报和严肃内容。
- 明确禁止卡通、拟人、emoji、粉色、霓虹和 3D。

### Cartoon

- 使用柔和粉/黄/蓝、圆润字体和具体拟人化物件。
- 适合教育、入门和轻松内容，不承载问责性结论。
- 用“戴猫耳的文件夹”“分成三格的礼物盒”等具体名词控制图标。

### Tech Dark

- 使用午夜蓝背景、青/品红霓虹、玻璃卡片、电路网格和线性发光图标。
- 适合技术架构和数据看板。
- 明确禁止白底、暖色、儿童化插画、动物和 emoji。

## Prompt 结构

按以下顺序编写，降低模型自由发挥：

1. **全局定调**：画幅、背景、配色、字体、留白和图标风格。
2. **布局约束**：顶部标题区、从左到右的栏目、底部目标条及大致占比。
3. **逐区内容**：逐字写出栏目标题和条目；每条附具体图标描述。
4. **视觉收尾**：说明分隔线、卡片、边框或强调色的使用方式。
5. **绝对禁止**：列出与目标风格冲突的具体元素。

使用具体的空间语言，例如“从左到右三个等宽栏目”，不要只写“排版清晰”。使用具体色名或色值，不要只写“高级配色”。

## 最小示例

```text
生成一张 16:9 横版信息图。极简商务风，雾灰白背景，雾蓝和暖米色分区，
橄榄金强调；图中文字使用清晰克制的无衬线字体，标题加粗。仅呈现下方明确提供的标题和正文，不擅自翻译、补充或改写。顶部为全宽标题区，下方从左到右三个等宽栏目。

顶部：主标题“订单服务 API”，副标题“下单到履约的核心链路”。

左栏“核心能力”：
1.（文档线图标）幂等创建：重复请求返回同一结果
2.（库存线图标）库存锁定：下单后保留 15 分钟
3.（状态机线图标）状态流转：待支付→已支付→已发货→完成

中栏“调用流程”：01 校验入参 → 02 锁库存 → 03 创建订单 → 04 拉起支付 → 05 回调更新。

右栏“接入规则”：
1.（钥匙线图标）幂等键必传
2.（时钟线图标）超时后重新查询订单状态
3.（盾牌线图标）验签失败时拒绝支付回调

底部目标条：“让一次下单的完整链路一眼可见。”
绝对禁止：卡通、拟人动物、emoji、粉色、霓虹、3D、渐变填充。
```

示例中的事实仅演示写法。实际生成时必须替换为源材料能够确认的内容。

## 常见问题

| 问题 | 调整方式 |
|---|---|
| 三栏挤成一团 | 减少到每栏 3–5 条；使用横版；重申“三个等宽栏目” |
| 出现非预期语言或自动翻译 | 明确“仅呈现下方提供的标题和正文，不擅自翻译或补充” |
| 文字模糊、叠字 | 缩短 prompt 和单条说明；减少小字号内容；提高横版尺寸 |
| 图标变成随机几何形 | 为每条写出具体物件与线条/拟人化方式 |
| Business 出现卡通 | 在结尾补充卡通、动物、笑脸、emoji、粉色等禁词 |
| Tech Dark 不够深 | 写明午夜蓝色值、半透明玻璃卡片、发光边框和电路网格 |
| 配色像默认 PPT | 写明低饱和、莫兰迪和具体色名，禁止高饱和红蓝原色 |
